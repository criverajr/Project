A conveyor belt has packages that must be shipped from one port to another within days days.

The i^th package on the conveyor belt has a weight of weights[i]. Each day, we load the ship with packages on the conveyor belt (in the order given by weights). We may not load more weight than the maximum weight capacity of the ship.

Return the least weight capacity of the ship that will result in all the packages on the conveyor belt being shipped within days days.


Variables:
int days - days in which we want the packages shipped
int[] weights - an array of all the package weights we want shipped
int low - heaviest package from the array
int high - total weight of the array
int w - temp variable for comparing array values to build low and high
int daysNeeded - for use in canShip to tally days needed to ship
int currentLoad - for use in canShip to tally load per day
int result - gives us our final answer

Implementation:
- Create shipWithinDays class that carries weights array and days int
- Identify heaviest package and total weight of packages within class
- Create canShip class that returns a boolean if a load and day combo is true or false
- Call canShip within shipWithinDays to loop possibilities until low overtakes high
- Return result
- Create main class that calls Solution objects to test the accuracy of result
